# Research index

> A working map of the deck. Start with a dataset, follow the `Thread it to` links, then use backlinks to see the recurring questions it shares with the rest of the vault.

## The story, roughly in order

1. [[datasets/00-john-snow-cholera|John Snow’s Cholera Map]] — putting events in place.
2. [[datasets/01-1890 census|1890 Census]] — turning people into sortable records.
3. [[datasets/03-project-gutenberg|Project Gutenberg]] — books becoming machine-readable text.
4. [[datasets/02-iris|Iris]] — the small benchmark with the long afterlife.
5. [[datasets/04-Boston Housing|Boston Housing]] — a city compressed into columns.
6. [[datasets/05-human-genome|Human Genome Project]] — a reference becomes infrastructure.
7. [[datasets/06-mnist|MNIST]] — a clean task becomes a shared score.
8. [[datasets/07-enron|Enron Email Corpus]] — records repurposed as language data.
9. [[datasets/08-openstreetmap|OpenStreetMap]] — maps as a living commons.
10. [[datasets/09-netflix-prize|Netflix Prize]] — preference as an identifying signal.
11. [[datasets/10-common-crawl|Common Crawl]] — web archive as raw material.
12. [[datasets/11-imagenet|ImageNet]] — taxonomy becomes vision infrastructure.
13. [[datasets/12-meds|MEDS I & II]] — biometric evaluation with an acquisition history.
14. [[datasets/13-webtext|WebText / GPT-2]] — a model's upvote-shaped reading list.
15. [[datasets/14-laion-5b|LAION-5B]] — web-scale image-text associations.

## Loose threads

- Dataset versions, licenses, and indexes drift. A number is only as useful as its release label.
- “Publicly accessible,” “public domain,” “openly licensed,” and “consented for this reuse” are different claims.
- Link a new note from one story thread and one concern thread, not just from this index.
